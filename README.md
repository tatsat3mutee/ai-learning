# AI Engineering Notebook

A single-page, offline-friendly revision notebook for AI engineering, machine learning, deep learning and CS/maths foundations, built and maintained by [Tatsat Pandey](https://tatsatpandey.com).

**Open it:** https://tatsat3mutee.github.io/ai-learning/ (or download `index.html` and open it in any browser).

## What's inside

| Track | Covers |
| --- | --- |
| AI engineering | Production RAG, agent harnesses, inference and serving, evals, AI security, fine-tuning and post-training (LoRA/QLoRA, SFT, DPO), and a dated "what's new" module (looped transformers, hybrid attention, MoE, RLVR) |
| Machine learning | Foundations, data prep, regression, classification, trees and ensembles, SVM, Bayes, clustering, PCA |
| Deep learning | Perceptrons and backprop to CNNs, RNNs and transformers |
| Foundations | Probability and statistics, linear algebra, calculus and optimization, programming and DSA, databases |
| Practice | Coding exercises with starter code, solutions and expected output |
| Formulas | Every formula from the lessons on one sheet |

Progress (lessons read, exercises solved) is saved in your browser's localStorage.

## Projects linked from the notebook

- **LogLens-Granite**: fine-tuning IBM Granite-4.1-3B with QLoRA SFT + DPO for Java microservice log triage (Module 6, project lesson).
